Este projeto usa `AGENTS.md` como fonte única de verdade para o pipeline de
agentes (compatível com Cursor e Codex). Leia `AGENTS.md` primeiro, depois
os arquivos em `skills/*/SKILL.md` na ordem numérica.

Não duplique instruções aqui — se `AGENTS.md` for editado, este arquivo não
precisa mudar.
